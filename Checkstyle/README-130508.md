**Aluno:** 130508 — João Miguel  
**Projeto:** BattleShip2

## 1. Regra escolhida

Foi selecionada a regra `ConstantName` do Checkstyle, responsável por verificar se os nomes das constantes Java respeitam a convenção `UPPER_SNAKE_CASE`.

A expressão regular utilizada foi:

`^[A-Z][A-Z0-9]*(_[A-Z0-9]+)*$`

## 2. Testes realizados

### Execução com falha

[Consultar execução com falha](https://github.com/LEI-130508/Battleship2/actions/runs/42516411101)

Foi introduzida deliberadamente uma constante com o nome `maxShips`, que não respeita a convenção estabelecida. O Checkstyle identificou a violação e o quality gate falhou.

### Execução com sucesso

[Consultar execução bem-sucedida](https://github.com/LEI-130508/Battleship2/actions/runs/42516756551/job/128841347352?pr=15)

A constante foi renomeada para `MAX_SHIPS`, respeitando a convenção `UPPER_SNAKE_CASE`. Após a correção, o Checkstyle executou com sucesso.

## 3. Limitações do Checkstyle

O Checkstyle permite verificar automaticamente se os nomes dos identificadores respeitam determinadas convenções, mas não consegue garantir que esses nomes sejam claros ou significativos. Por exemplo, uma constante denominada `ABC` cumpre a regra definida, apesar de o seu nome não explicar a sua finalidade. Assim, a ferramenta complementa a revisão humana do código, mas não a substitui.
