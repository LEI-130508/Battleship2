# Relatório de Implementação do Quality Gate (Qodana) - 130507


## 1. Descrição do Code Smell

* **Nome do Smell:** Long Method
* **Métrica / Limiar:** Métodos com mais de 30 linhas de código (LOC > 30).
* **Justificação:** Métodos excessivamente longos prejudicam a legibilidade, dificultam a manutenção e violam o Princípio da Responsabilidade Única (SRP - *Single Responsibility Principle*), aumentando a complexidade ciclomática e a propensão à introdução de erros.

---

## 2. Configuração do Linter (JetBrains Qodana)

Para automatizar a deteção deste code smell foram criados e configurados os seguintes artefactos:

1. **Configuração Base (`qodana-130507.yaml`):**
   * Configurado para utilizar a imagem comunitária da JVM (`jetbrains/qodana-jvm-community:2024.2`).
   * Aponta para o perfil isolado de inspeções em `.qodana/profiles/profile-130507.yaml`.
   * Define como condição de falha (*Quality Gate*) qualquer violação com severidade superior a zero (`any: 0`).

2. **Perfil de Inspeções (`.qodana/profiles/profile-130507.yaml`):**
   * Perfil baseado em `base: empty` para mitigar ruído de outras verificações do motor do IntelliJ.
   * Regra ativada: `MethodWithTooManyLines` / `OverlyLongMethod` com o limiar configurado para 30 linhas (`m_limit: 30`).

3. **Workflow de GitHub Actions (`.github/workflows/qodana-smell-130507.yaml`):**
   * Disparado em eventos de `pull_request` e `push` direcionados ao ramo `main`.
   * Executa a action oficial `JetBrains/qodana-action@v2024.2` apontando estritamente para o ficheiro `qodana-130507.yaml`.

---

## 3. Regra de Proteção do Ramo (`main`)

Para garantir a conformidade contínua do repositório, foi configurada uma regra de proteção no GitHub (*Branch Protection Rule*) para o branch `main`:
* **Require a pull request before merging:** Não são permitidos commits diretos no ramo principal.
* **Require status checks to pass before merging:** A execução do job `Qodana smell gate 130507` é estritamente obrigatória para que qualquer Pull Request possa ser aceite.
